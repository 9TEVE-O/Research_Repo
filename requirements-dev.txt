# Development / test dependencies for Research_Repo.
#
# Runtime dependencies are pinned (with hashes) in requirements.lock; test
# dependencies (pytest and its own transitive deps) are pinned (with hashes)
# in requirements-dev.lock, generated from requirements-dev.in via:
#
#   pip-compile --generate-hashes --output-file=requirements-dev.lock requirements-dev.in
#
# requirements.lock uses --generate-hashes, which puts pip into
# hash-checking mode: every requirement resolved in the same invocation must
# then carry a hash. Install both sets, each with --require-hashes:
#
#   pip install --require-hashes -r requirements.lock
#   pip install --require-hashes -r requirements-dev.lock
