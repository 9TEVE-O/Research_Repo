# Prompt Engineering Guide

## CODE BEHAVIOUR: ALL PROJECTS

Core behavioral principles for all projects:

- Maintain consistency across all modules
- Document assumptions and constraints
- Handle edge cases gracefully
- Validate inputs before processing
- Log significant operations
- Implement proper error handling

## TEACH THE ROBOT SPECIFIC

### Audio Engineering
- Implement audio pipeline for signal processing
- Handle sampling rates and bit depths
- Normalize audio levels across sources
- Support multiple audio codecs
- Validate audio format compatibility

### React/JS Conventions
- Follow ES6+ standards
- Use functional components with hooks
- Implement proper state management patterns
- Maintain consistent naming conventions (camelCase for variables, PascalCase for components)
- Use PropTypes or TypeScript for type checking
- Organize imports alphabetically
- Keep components modular and reusable
- Implement error boundaries for error handling
- Use meaningful variable and function names
- Write tests for critical functionality
